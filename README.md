# 星空花火フェスティバル2026 — 架空イベントWebサイト

HTML・CSS・JavaScriptを使用して制作した、架空の花火イベント「星空花火フェスティバル2026」の公式サイト風Webサイトです。

職業訓練校のWebサイト制作課題として制作しました。

イベント情報の掲載に加え、来場者・協賛企業・出店希望者など、目的の異なる利用者が必要な情報にアクセスしやすいサイト構成を意識しています。

**[Webサイトを開く（Live Demo）](https://yumeto101-eng.github.io/fireworks-festival/)**

※ 実際のイベントではありません。掲載しているイベント・企業・チケット等の情報はデモ用です。

## 主な機能

- **レスポンシブデザイン**：PC・スマートフォンなどの画面幅に対応
- **ナビゲーションメニュー**：ハンバーガーメニューによるページ移動
- **画像スライダー**：Slickを利用した花火画像の自動スライド
- **画像拡大表示**：Lightboxによる画像の拡大表示
- **イベント情報の表示**：開催概要、プログラム、出演者、出店情報など
- **チケット選択UI**：枚数の増減、購入内容・合計金額の表示
- **各種応募フォーム**：協賛・出店・お問い合わせの入力画面（送信はデモ）
- **制作紹介ページ**：サイトの目的、設計、工夫した点を紹介

## 実行方法

### 1. Webブラウザで閲覧

以下のURLからアクセスできます。

https://yumeto101-eng.github.io/fireworks-festival/

ブラウザから閲覧する場合、インストールは不要です。

### 2. ソースコードから実行

1. GitHubからリポジトリをダウンロード、またはクローンします。
2. `index.html` をWebブラウザで開きます。
3. メニューから各ページに移動できます。

外部ライブラリやWebフォントの一部をCDNから読み込んでいるため、インターネット接続が必要です。

## 操作方法

1. トップページからイベント情報を確認します。
2. ナビゲーションメニューを使用して、各ページへ移動します。
3. 花火画像をクリックすると、拡大表示できます。
4. チケットページでは、チケットの枚数を変更して合計金額を確認できます。
5. 協賛・出店・お問い合わせページでは、フォームの入力画面を確認できます。
6. 制作紹介ページでは、サイト設計や制作意図を確認できます。

※ 実際のチケット購入、決済、フォーム送信には対応していません。

## 制作で工夫した点

### 1. 利用者ごとの導線設計

来場者・協賛企業・出店希望者という異なる利用者を想定し、それぞれが必要な情報へ進めるサイト構成を考えました。

特に協賛企業向けページでは、協賛メリット、掲載イメージ、プラン内容を確認してから応募フォームに進めるようにしています。

### 2. 統一感のあるデザイン

夜空をイメージしたネイビーを基調に、ゴールドをアクセントとして使用しました。

ページごとに異なる情報を掲載しながらも、ヘッダー・見出し・カード・フォームなどのデザインを統一しました。

### 3. CSSの共通化

`.section-title` や `.card-area` など、複数ページで使うスタイルを共通クラスとして整理しました。

また、CSSをセクションごとに分類し、修正する場所を把握しやすいように工夫しました。

### 4. レスポンシブ対応

Flexbox、CSS Grid、メディアクエリを使用し、画面幅によってレイアウトが変わるようにしました。

スマートフォンではハンバーガーメニューを使用し、限られた画面幅でも操作できるようにしています。

### 5. JavaScriptによる操作機能

ハンバーガーメニューの開閉、花火画像のスライド・拡大表示など、画面上の操作機能を実装しました。

また、チケットページには枚数の増減に応じて購入内容・合計金額を更新するデモ機能を設けています。
